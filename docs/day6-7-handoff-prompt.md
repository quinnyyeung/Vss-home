## 新增沉淀（详见 `.claude/skills/vss-ui-restore/SKILL.md`，已经更新到最新）

- **图标系统**：`src/components/Icons.jsx`，除箭头外的图标用真实 PNG 走 CSS `mask-image` 上色，箭头统一用手写 SVG 的 `ChevronIcon`（`direction` 参数控制方向）
- **`min-w-0` 响应式坑**：`flex-1` 容器默认不会缩得比内容还窄，新增可能撑宽的模块记得加 `min-w-0`，图表这类不能缩水的内容外面包 `flex flex-wrap`
- **`@container` 容器查询**：卡片内部想按自身宽度（不是页面整体断点）响应布局时用这个，Tailwind v4 原生支持
- **mock 数据长文本要写完整句子**，不要手打"..."模拟截断，截断交给 CSS `truncate`
- **无路由库的页面导航模式**：参考 `App.jsx` 里 `page` 状态切换首页/详情页的写法
