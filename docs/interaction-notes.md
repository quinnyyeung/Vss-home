# 首页交互说明参考（设计方原始交互稿）

这份文档来自设计方之前写好的交互说明图（Day 4 用户补充发的两张图），记录首页各模块的完整交互规则。`7day-execution-plan.md` 里每天的任务描述比较概括，这份文档是更细的交互补充，遇到某个模块该怎么交互拿不准时先来这里查，仍然找不到再问用户，不要自己猜。

> 注：demo 项目没有真实路由/详情页，文档里写的"跳转列表页/详情页"这类描述，目前统一按"仅做视觉反馈（点击态、hover 态），不建新页面"来实现（Day 4 用户已确认）。以后如果要做成真跳转，需要用户重新确认。

## ① 任务中心

- 默认态：分类下如果有待处理任务，第一项用特殊样式（浅绿底）+ 展示数字角标；如果没有待处理任务，整个分类是纯白色列表，不展示角标。
- hover / click 态：待办项 hover、点击时颜色比默认态更深一档；普通项也有对应的 hover/点击反馈。

## ② 数据看板 - 履约数据 tab

- 城市下拉切换后，下方指标卡片联动更新数据。
- 指标卡片按状态分三类：未达标（红）、已达标（绿）、数据缺失占位（灰）。
- 每张卡片标题旁的 icon，hover 后显示该指标的解释文案，文案最大宽度 272px，超出换行。

## ③ 数据看板 - 采购订单数据 tab

- tab hover 时显示提示文案，标题旁 icon hover 也有说明。
- 城市下拉联动折线趋势图。
- 图上有最近两周数据的标记点，点击图例可切换某条趋势线的显示/隐藏。

## ④ 评级汰换 - 评级结果 tab

- 点击"具体说明"弹出说明浮层，点击浮层里的"关闭"按钮关闭。
- 悬浮在被截断的说明文字上，展示完整说明内容。
- 折线图 hover 显示数据浮层。
- 右侧表格展示分页信息。

## ⑤ 评级汰换 - 汰换预警 tab

- 内部有"商汰换 / SKU汰换"子 tab 切换（Day 3 已实现）。
- 列表分页器；点击某条的"查看详情"跳转（demo 里做视觉反馈）。

## ⑥ 商家信息

- 供货规则超过一行时折行展示；经营品类完整展示，用"、"分隔，超过一行也是折行（不是省略号截断）。
- 点击"更多"跳转供应商信息页；hover"更多"文字变色。

## ⑦ 公告栏

- 默认选中"最新" tab：按发布时间排序，展示各条不同类型的标签（预警/通知/规则/函件）。
- 切换到"预警/通知/规则/函件"这些具体分类 tab 后：**不展示标签**（该维度下所有条目类型已确定），按发布时间排序。
- 点击"更多"跳转通知列表；点击某条信息跳转对应通知详情。
- 预警类通知的展示格式：直接展示采购单号，点击跳转对应采购单详情。

## ⑧ 培训中心

- 点击"更多"跳转培训中心。
- 数字指标旁的 icon hover 显示解释文案。
- 点击课程卡片弹出课程列表弹窗。

## ⑨ 常见问题

- 点击"知识库"跳转知识库页面。
- 点击问题列表某一项跳转知识库里对应的问答详情。

## ⑩ 侧边悬浮图标入口集合（联系方式 / 意见反馈 / 首页评价 / 问卷调研）

**这个模块还没有排进 7 天计划，Day 4 不做，先记录规则备用。**

- 默认收起态、hover/点击态展开显示对应内容，箭头指向触发的图标，距离图标边缘 20px。
- 点击"联系方式"展开财务结算电话等联系信息。
- 点击"意见反馈"跳转反馈页。
- 点击"问卷调研"跳转问卷链接，如果有多个问卷通过列表供选择。
- 点击"首页评价"展开评价浮层：
  - 默认是"请选择"态星标评分；hover/点击星标时旁边文案跟着变化。
  - 选择评分、输入建议（选填，不填也能提交）后点击"提交"按钮。
  - 未评分就点提交会有校验提示；提交成功/失败都有对应反馈样式。
- 图标集合支持长按拖动到页面其他位置。
